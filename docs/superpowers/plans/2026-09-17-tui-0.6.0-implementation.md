# simpleWorkflow TUI 0.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the simpleWorkflow Textual TUI into a professional, read-only operational inspection tool with compact task context, attempt history, navigable resources, searchable/copyable file and log viewing, improved failure diagnosis, and responsive HPC-friendly layout.

**Architecture:** Keep SQLite and `MonitorSnapshot` as the persisted-state boundary, then split the presentation layer into focused modules: attempt-aware read model, resource discovery, reusable text viewer, task Inspector/resource browser, and a smaller application shell in `tui.py`. Preserve the five top-level views and all engine/plain/PBS/restart semantics.

**Tech Stack:** Python 3.10–3.12, Textual >=8.2,<9, Rich >=13.7, pytest, pytest-cov, Ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-09-17-tui-0.6.0-design.md`

## Global Constraints

- SQLite remains the source of truth.
- `WorkflowEngine` remains the only execution engine.
- No state schema change.
- No daemon, service, REST API, scheduler controller, or parallel mutable TUI workflow state.
- Preserve local/PBS execution, restart-safety, `NO_COLOR`, core-only install, and `swf run --ui plain`.
- Preserve exactly five top-level views: Monitor, Ciclos, Campanha, Problemas, Logs.
- `q` closes only the monitor; it never cancels execution.
- Native persisted cycles remain authoritative; unrolled-cycle grouping stays conservative and presentation-only.
- Resource discovery prefers structured provenance over free-text parsing.
- Text inspection is read-only; no editor, shell, arbitrary recursive directory browser, rerun, retry, or cancel controls.
- Use TDD for every behavior change and commit after each independently testable task.
- Avoid fragile snapshot-only tests; assert behavior, state, focus/navigation, and resource contracts.
- Live JACI/PBS validation must not be claimed unless actually executed there.

```python
def _attempt_history(
    state: WorkflowState,
) -> dict[tuple[str, str], tuple[AttemptSnapshot, ...]]:
    rows = state.connection.execute(
        """
        SELECT run_id, cycle_id, task, attempt, status, return_code, reason,
               attempt_path, started_at, finished_at
        FROM attempt_history
        ORDER BY cycle_id, task, COALESCE(started_at, '') DESC, run_id DESC, attempt DESC
        """
    ).fetchall()
    grouped: dict[tuple[str, str], list[AttemptSnapshot]] = {}
    for row in rows:
        directory = state.resolve_path(str(row[7]))
        if directory is None:
            continue
        key = (str(row[1] or ""), str(row[2]))
        grouped.setdefault(key, []).append(
            AttemptSnapshot(
                run_id=str(row[0]),
                cycle_id=str(row[1]) if row[1] else None,
                task_name=str(row[2]),
                attempt=int(row[3]),
                status=str(row[4]),
                return_code=row[5],
                reason=str(row[6]) if row[6] else None,
                directory=directory,
                started_at=str(row[8]) if row[8] else None,
                finished_at=str(row[9]) if row[9] else None,
            )
        )
    return {key: tuple(items) for key, items in grouped.items()}
```

Update `_task_snapshot(...)` to accept `attempts` and pass grouped tuples for native cycles, unrolled cycles, and root tasks.

- [ ] **Step 6: Implement conservative text detection**

Use a bounded byte probe, not extension alone:

```python
def is_probably_text(path: Path, *, sample_size: int = 8192) -> bool:
    try:
        sample = path.open("rb").read(sample_size)
    except OSError:
        return False
    if b"\x00" in sample:
        return False
    try:
        sample.decode("utf-8")
    except UnicodeDecodeError:
        return False
    return True
```
