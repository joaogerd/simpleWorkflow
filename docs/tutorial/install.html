O simpleWorkflow é desenvolvido no GitHub. Enquanto a distribuição via índice de pacotes não for a fonte oficial de instalação, o caminho documentado deve partir do repositório.

1. Requisitos

Você precisa de Python 3.10 ou superior, Git e acesso ao terminal.

python3 --version
git --version
Não comece por pip install simpleworkflow[tui] a menos que uma distribuição oficial em índice de pacotes esteja publicada e documentada. Para o estado atual do projeto, use o repositório GitHub.

2. Crie um ambiente Python isolado

É recomendado instalar a ferramenta em um ambiente virtual para não misturar dependências com o Python do sistema.

python3 -m venv ~/.venvs/simpleworkflow
source ~/.venvs/simpleworkflow/bin/activate
python -m pip install --upgrade pip

Quando o ambiente estiver ativo, o prompt normalmente mostra algo como (simpleworkflow).

3. Baixe o repositório

git clone https://github.com/joaogerd/simpleWorkflow.git
cd simpleWorkflow

Se você já possui o repositório, entre nele e atualize:

git pull

4. Instale o simpleWorkflow

Para uso normal com a interface TUI:

python -m pip install ".[tui]"

Isso instala o pacote a partir do diretório que você acabou de clonar, incluindo Textual e Rich para a interface de terminal.

Resultado esperado: os comandos swf e simpleworkflow passam a existir dentro do ambiente Python ativo.

5. Verifique antes de continuar

swf --help
swf validate examples/hello.yaml
swf plan examples/hello.yaml

Se esses comandos funcionarem, a instalação está pronta. Você pode seguir para o tutorial básico.

6. Como atualizar

Como a instalação veio do checkout local, atualize o código e reinstale quando necessário:

cd /caminho/para/simpleWorkflow
git pull
python -m pip install ".[tui]"

7. Instalação para desenvolvimento

Quem vai modificar o código deve usar instalação editável com as dependências de desenvolvimento:

python -m pip install -e ".[dev]"

Nesse modo, mudanças no código-fonte são usadas imediatamente, sem reinstalar o pacote a cada edição.
