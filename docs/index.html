O fluxo mental é pequeno

1. Descreva

Liste tarefas e dependências em YAML usando argumentos explícitos em argv.

2. Valide

Use swf validate e swf plan antes de executar.

3. Execute

swf run usa TUI no terminal interativo ou saída compacta em batch/CI.

4. Diagnostique

Estado, tentativas, stdout/stderr e problemas permanecem em .simpleworkflow/.
