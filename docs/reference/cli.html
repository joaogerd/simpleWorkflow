Comandos e opções CLI.

O que cada subcomando faz, quando altera estado e quais opções aceita.

ComandosVisão geralrunplanvalidatestatusexplainresetmonitorcapture-tuimigrateOpções comuns

1. Visão geral

ComandoObjetivoCria/altera estado?
runExecutar tarefas.Sim, exceto --dry-run.
planMostrar o plano e ordem de execução.Não.
validateValidar YAML e seleção.Não.
statusLer estado persistido.Não.
explainExplicar estado/decisões de execução.Não.
resetLimpar estado reutilizável atual.Sim.
monitorAbrir TUI read-only sobre estado existente/configurado.Não.
capture-tuiGerar screenshot SVG determinístico.Não.
migrateInspecionar/migrar banco de estado legado.Somente sem --check.

2. swf run

swf run WORKFLOW [opções]
OpçãoSignificado
--forceExecuta novamente tarefas que seriam reutilizadas.
--dry-runRenderiza/valida invocações sem criar estado de execução.
--ui auto|tui|plainModo de apresentação. Default: auto.
--task NAMESeleciona uma tarefa e inclui suas dependências; repetível.

3. swf plan

swf plan workflow.yaml

Mostra o que seria executado e a ordem de dependências. Aceita --task e opções de ciclo.

4. swf validate

swf validate workflow.yaml

Valida schema, dependências, templates e seleção. Deve ser o primeiro comando usado após editar o YAML.

5. swf status

swf status workflow.yaml

Lê o estado persistido, se existir, sem executar nada.

6. swf explain

swf explain workflow.yaml

Fornece explicação operacional sobre tarefas/estado e também aceita seleção de tarefas.

7. swf reset

swf reset workflow.yaml

Limpa estado reutilizável atual para permitir nova execução. Histórico de runs/attempts é preservado.

Use reset com intenção clara. Para apenas executar novamente sem redefinir o estado atual, run --force costuma ser mais explícito.

8. swf monitor

swf monitor workflow.yaml
swf monitor workflow.yaml --refresh-seconds 2

Abre o monitor read-only. --refresh-seconds controla o intervalo de atualização, default 1 segundo.

9. swf capture-tui

swf capture-tui workflow.yaml \
  --view monitor \
  --size 140x45 \
  --output monitor.svg
OpçãoValores
--viewmonitor, cycles, campaign, problems, logs.
--sizeCOLSxROWS; default 120x35.
--output PATHArquivo SVG de destino; obrigatório.

10. swf migrate

swf migrate workflow.yaml --check
swf migrate workflow.yaml
OpçãoSignificado
--checkInspeciona formato sem modificar o banco.
--legacy-workflow INSTANCESeleciona uma instância legada quando o banco antigo é ambíguo.

11. Opções comuns

Estado

OpçãoSignificado
--workdir PATHDiretório de estado. Default: .simpleworkflow ao lado do YAML. Caminho relativo explícito é resolvido do diretório corrente.
--debugMostra traceback técnico.
--color auto|always|neverControle de cor do terminal.

Seleção de ciclos

OpçãoSignificado
--cycle-time TIMESeleciona um ciclo ISO-8601 explícito; repetível.
--from TIMESobrescreve cycle.start.
--to TIMESobrescreve cycle.end.
--step DURATIONSobrescreve o passo, ex. PT6H.

Exemplos práticos

# validar e planejar
swf validate workflow.yaml
swf plan workflow.yaml

# rodar somente uma tarefa e suas dependências
swf run workflow.yaml --task forecast

# rodar um ciclo específico
swf run workflow.yaml --cycle-time 2026-10-03T12:00:00Z

# saída adequada para batch
swf run workflow.yaml --ui plain --color never

# observar de outro terminal
swf monitor workflow.yaml
