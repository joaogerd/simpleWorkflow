# Support and issue reporting

Use the public [issue tracker](https://github.com/joaogerd/simpleWorkflow/issues) for installation questions, bug reports, documentation issues and feature proposals. Search existing issues first.

Include the installed simpleWorkflow version, Python version, platform, command, sanitized YAML, a minimal reproducible example and observed error. For scheduler problems, indicate whether you used real PBS or a test double. For interrupted runs, describe the outcome without publishing confidential state files.

Do not post credentials, personal information or sensitive institutional paths publicly. If reporting privately is necessary, verify that the repository provides an appropriate private channel before sharing details.

Maintenance and support are currently best-effort; there is no promised service-level agreement. Compatibility-sensitive changes are reviewed and merged through development branches before reaching the stable release branch.
